# TalonBot — архитектура (публичный обзор)

Документ описывает **общую структуру** проекта без раскрытия проприетарной реализации.

---

## Компоненты

| Компонент | Назначение |
|-----------|------------|
| **Launcher (GUI)** | Окно настройки: авторизация, выбор МО/врача, запуск/остановка |
| **Bot engine** | Фоновый цикл: опрос талонов → попытка записи |
| **API client** | Работа с официальным порталом napriem.info |
| **License gate** | Проверка активации до входа в приложение |
| **Config layer** | Кэш больниц, пользовательские настройки, сессия |

---

---

## Лицензирование (концепция)

1. При первом запуске показывается **код компьютера** (8 символов).
2. Покупатель отправляет код автору.
3. Автор выдаёт ключ формата `TBOT-XXXX-YYYY`, привязанный к этому ПК.
4. Ключ сохраняется локально; повторная активация на другом ПК не работает.

Детали реализации (алгоритмы, секреты) **не публикуются**.

---

## Ограничения региона

Портал [napriem.info](https://napriem.info) обслуживает **только Брянск и Брянскую область**.
Приложение не предназначено для других регионов РФ.
